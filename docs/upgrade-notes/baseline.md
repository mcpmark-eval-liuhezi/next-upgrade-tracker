# Upgrade Baseline

- **Baseline upstream release tag:** `v16.4.6`
- **Tracked in issue:** #7 (Track Next.js releases)

## Notes

`v16.4.6` is a backport release for the `lts-active` channel that does not include all pending canary features. It pins Tailwind to 4.3.3 in create-next-app and tests, adds automatic route handler response compression, and includes Turbopack GC fixes for dev.

Questions/upstream discussion can go in the upstream Next.js repo under: App Router, Feedback, Help, Ideas, Polls, RFC, Security, Show and tell, Triage, and Turbopack Error Report.
